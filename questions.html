Html Questions

article

An article element is appropriate when the content is a self contained, independently distributable piece that makes sense on its own, without needing the surrounding page context

aside

element holds content that is related to but not essential for understanding the main content

details

When a details element is opened, its contents a summary tag which becomes visible to the user. When it is closed, only the summary label is shown, while the inner content is hidden

figcaption

The figcaption element provides a visible caption or legend that describes the contents of its parent figure element.

figure

A figure represents self contained content that can be moved elsewhere in the document and the figure tag and the figcaption work toegther

footer

A footer contains authorship, copyright, contact information

header

You may have multiple headers in one document, as long as they are not placed inside another header, footer, or address element

main

The main element contains the central content unique to the page—the part that directly fulfills the pages purpose

nav

A nav element contains major blocks of navigation links, such as menus, tables of contents, or key site navigation

section

A section is a semantic HTML element used to group content

summary

The summary element is the interactive label for a details block. It is the part the user sees and clicks to expand or collapse the hidden content
